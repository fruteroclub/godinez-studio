## Contextos

El wizard detecta el contexto del usuario y adapta:
- Las preguntas del wizard
- El SOUL.md del agente
- El flujo de acompañamiento

### Educación
Para estudiantes de bootcamps, cursos o talleres. El agente actúa como mentor.

### Profesional
Para entregables de trabajo (contenido, desarrollo, análisis). El agente actúa como partner de ejecución.

### Personal
Para hackathons y emprendimientos. El agente actúa como co-founder temporal.
